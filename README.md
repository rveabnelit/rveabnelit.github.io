# LANI LOUD — сайт музыкального проекта

**Сайт опубликован:** https://rveabnelit.github.io/
**Репозиторий:** https://github.com/rveabnelit/rveabnelit.github.io (публичный, GitHub Pages, HTTPS автоматически)

Обновление сайта после правок — одной командой:

```powershell
python design\publish.py "что поменял"
```

Скрипт пересоберёт архив, закоммитит изменения и отправит на GitHub. Через минуту-две правки появятся на сайте.

---

Статический сайт: **HTML + CSS + JS, без сборки и без зависимостей.**
Открывается двойным щелчком по `index.html`, кладётся на любой хостинг как есть.

## 1. Что на сайте

1. **Hero** — фото первой страницы: ты с гитарой на крыше, ночной город, скелет-дудл и тёплое окно справа; поверх — логотип, слоган «Какие-то песни для каких-то людей» и две кнопки, справа сверху цитата из «17». Логотип стоит так, что просвет до верха страницы и до головы одинаковый (см. раздел 10). Видео-баннер из `Video-banner 1.mov` лежит в запасе.
2. **Музыка** — 4 релиза. Первым стоит грядущий «Август» (полароид, бейдж *Скоро*), дальше вышедшие «17», «Я улетаю», «Свет пронести» с рабочими ссылками на все площадки. Под сеткой — кнопки быстрого прослушивания и ссылки на профиль артиста.
3. **Видео** — клип «Свет пронести»: по клику по постеру прямо на странице загружается плеер YouTube (без перехода на другой сайт).
4. **Пресс-релизы** — 4 материала. Первым — грядущий «Август» (*Скоро*), дальше вышедшие с датами и ссылками «Слушать». В шапке блока — скачивание пресс-кита.
5. **Фото** — полоса из 5 настоящих фотографий, без артов с надписями.
6. **Футер** — логотип, слоган, соцсети и контакты для редакторов и лейблов.

Из сайта убраны **Концерты**, **Обо мне** и пункт меню **Контакты**. Навигация: Музыка · Видео · Пресс-релизы.

**Порядок релизов** — везде одинаковый: сверху грядущий, дальше вышедшие от новых к старым.

| | Релиз | Дата |
|---|---|---|
| 1 | Август | готовится к выходу |
| 2 | 17 | 30.08.2026 |
| 3 | Свет пронести | 16.05.2025 |
| 4 | Я улетаю | 09.08.2024 |

Этот порядок держится в трёх местах: сетка «Музыка», блок «Пресс-релизы» и кнопки быстрого прослушивания под волной. Когда выйдет «Август», он останется первым (просто поменяются бейдж и дата), а новый грядущий релиз встанет перед ним. Новый вышедший сингл добавляется сразу после «Августа».

## 5. Шрифты и сборка

**Шрифты лежат рядом с сайтом**, внешний CDN не используется. Файлы — в `assets/fonts/` (8 файлов, 139 КБ: кириллица и латиница для Oswald 300/400, Inter 300 и Neucha 400), правила — в [css/fonts.css](css/fonts.css). Пересобрать можно скриптом:

```powershell
python design\fetch_fonts.py     # скачает нужные начертания и перепишет css/fonts.css
```

**Сборка для хостинга** — папка `dist` и архив `lani-loud-site.zip`:

```powershell
python design\make_dist.py       # пересобирает dist и архив из текущих файлов
python design\set_domain.py laniloud.ru   # подставляет ваш домен во все места
```

## 6. Как выложить

**Сайт уже выложен на GitHub Pages** — см. шапку файла. Дальше обновления идут через `python design\publish.py "описание правок"`.

Если позже понадобится переехать на свой хостинг или поднять копию:

1. **Свой домен к этому же репозиторию** — в настройках репозитория Pages → Custom domain, у регистратора прописать CNAME на `rveabnelit.github.io`. Сайт остаётся на GitHub, но открывается по вашему адресу.
2. **Netlify Drop** — перетащите папку `dist` на https://app.netlify.com/drop.
2. **Vercel** — `vercel` из папки проекта.
3. **GitHub Pages** — Settings → Pages → Deploy from branch → `main` / `root`.
4. **Обычный хостинг (FTP/cPanel)** — залейте содержимое папки в `public_html`.

Перед заливкой можно удалить `design/` и `README.md` — сайту они не нужны.

## 10. Что правилось в фото

**Значки шапки.** С фото первой страницы сняты 11 иконок (VK, Telegram, YouTube, Instagram, SoundCloud слева; эквалайзер, нота, картинка, видео, профиль, меню справа). Скрипт нашёл их сам по яркости в верхней полосе:

```powershell
python design\retouch.py foto.png result.png --auto-band 0,120
```

Проверка: изменились только пиксели в полосе значков (нижняя изменённая строка — 57-я). Сравнение — [design/demo-icons-removed.jpg](design/demo-icons-removed.jpg).

**Гитара.** На исходнике головка грифа была нарисована неверно: колки вывернуты, видна лицевая сторона грифа со струнами вместо тыльной, гриф смещён относительно корпуса. Перерисовать геометрию пиксельно невозможно, поэтому гитара уведена в тень и читается силуэтом в контровом свете — неверные детали больше не бросаются в глаза:

```powershell
python design\retouch.py design\source\hero-base.png design\source\hero.png ^
  --silhouette "all:730,578 784,554 842,582 852,620 812,678 748,686 718,630" ^
  --silhouette "dark:846,600 1092,784 1092,866 854,692" ^
  --darken 0.22 --sil-blur 2 --sil-feather 3.5 --sil-flatten 9
```

Режим `all` затемняет всё внутри многоугольника (головка с колками), `dark` — только тёмные пиксели (гриф), поэтому огни города за грифом остались живыми. Исходник без правки гитары сохранён как `design/source/hero-base.png` — правку можно откатить. Сравнение — [design/demo-guitar.jpg](design/demo-guitar.jpg).

По-настоящему «починить» гитару можно только генеративной ретушью (Photoshop Generative Fill, нейросетевой inpaint) или новой генерацией кадра с исправленным промптом — пиксельными инструментами это не решается.

**Цитата из песни.** Строки «ПОКА СО МНОЙ / МОИ ПЕСНИ, / Я НЕУЯЗВИМ ДЛЯ / ЗЛОСТИ И ЛЕСТИ» стоят в правом верхнем углу, выше скелета-дудла, — как в первом референсе: линия сверху, четыре строки прописными, подпись «— 17» снизу. Стиль подобран под референс: шрифт Neucha (рукописный, с кириллицей), наклон `skewX(-8deg)`, прописные, SVG-фильтр `#scratched` даёт «процарапанные» края. Это текстовый слой, а не картинка: остаётся резким на любом экране и легко правится в `index.html`.

Почему не вставил готовый PNG: присланный фрагмент — 117×94 пикселя, а в hero блок занимает ~250 CSS px, то есть нужно ~500 px по ширине. При увеличении в 4–5 раз буквы расплываются, а вырезание по яркости тянет за собой серую дымку фона. Сравнение трёх вариантов — [design/demo-quote.jpg](design/demo-quote.jpg): референс, вырезанный PNG и шрифтовой вариант. Если пришлёшь исходник этого кадра в полном разрешении — вырежу надпись оттуда, там она будет чистой.

**Симметрия логотипа.** На кадре 1818×865 фон заполняет hero ровно по высоте, поэтому сдвинуть композицию по вертикали было нельзя: голова начиналась на 190 px от верха и упиралась в логотип, а увеличить логотип — значило налезть на голову. Решение: [design/extend_hero.py](design/extend_hero.py) добавляет сверху 150 px неба (градиент по столбцам, перепад на стыке — 0 из 255). Кадр становится 1818×1015, фон начинает обрезаться по ширине, и появляется свобода по вертикали.

Дальше позиция фона считается формулой:

```css
background-position: 100% max(0px, calc(19.17vw - 250px));
```

`19.17vw` — на какой высоте в кадре находится голова при масштабе по ширине окна, `250px` — на какой высоте hero её удержать. Так голова стоит на одном месте и на 1366, и на 1920 (проверено рендером на четырёх ширинах — [design/demo-hero-widths.jpg](design/demo-hero-widths.jpg)). При логотипе 437×133 px просвет сверху — 59 px, до волос — 64 px.

**На телефоне работает другой кадр.** Там фон уходит под текст, поэтому с добавленным небом лицо уезжало под заголовок и кнопки. Для телефона собирается `assets/img/hero-mobile.jpg` — то же фото **без** запаса неба (`design/source/hero-photo.png`), с полосой кадра 68vw: лицо остаётся выше заголовка. Файлы подгружаются по медиазапросу, так что телефон не тянет десктопный кадр и наоборот.
